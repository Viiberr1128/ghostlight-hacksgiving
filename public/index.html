Promises

    How it works

    1. Pick a repository and a GitHub username. Ghostlight looks for first-person commitments in recent issue and pull request threads.
    2. Ghostlight saves the commitments it finds. Recheck the inbox to see new evidence and status changes.
    3. Open the original sources and copy a follow-up to post yourself. A matching merge is evidence of a code change. Release status takes a separate check.
